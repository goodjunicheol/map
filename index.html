나이
카카오 길찾기 연결

카카오 대중교통 길찾기는 브라우저에서 바로 부를 수 없어서(CORS), 무료 중계 서버(Cloudflare Worker)를 거쳐야 해요. 처음 한 번만 설정하면 됩니다.

중계 서버 만드는 법 (5분)
  1. Cloudflare에 무료로 가입합니다.
  2. Workers & Pages → Create → Worker에서 이름을 kakao-proxy로 짓고 Deploy를 누릅니다.
  3. Edit code를 눌러 기존 코드를 지우고, 아래 코드를 복사해 붙여넣은 뒤 Deploy합니다. 사이트 주소(ALLOWED_ORIGINS)는 지금 이 페이지 주소로 자동으로 채워져 있어요.
  4. Worker의 Settings → Variables and Secrets → Add에서 종류는 Secret, 이름은 KAKAO_REST_KEY, 값은 카카오 REST API 키를 넣고 저장합니다.
  5. Worker 주소(https://kakao-proxy.….workers.dev)를 복사해 위 칸에 넣고 연결 테스트를 누릅니다.

키는 Cloudflare에만 저장돼서 사이트를 공개해도 노출되지 않아요. Worker는 내 사이트에서 온 요청만 받아요.

카카오 키·한도 안내
  1. developers.kakao.com에서 애플리케이션을 추가합니다.
  2. 앱의 [카카오맵] → [사용 설정] 상태를 ON으로 바꿉니다.
  3. REST API 키를 복사해 Worker의 KAKAO_REST_KEY에 넣습니다.

무료 한도: 대중교통 길찾기 하루 1,000회, 장소 검색 하루 100,000회. 유료 설정을 직접 켜지 않으면 요금이 나가지 않아요. Cloudflare Worker 무료 요금제로도 충분해요.

계산 옵션

길찾기 결과의 갈아타기마다 도보시간에 이 대기시간을 더해 환승 인정 시간(보통 30분)을 넘는지 판단합니다.
