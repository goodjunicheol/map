구간 직접 입력

API 키 없이도 쓸 수 있어요. 탄 순서대로 구간을 넣으면 지역별 환승 규칙에 따라 요금을 계산합니다.

나이
ODsay API 키 (자동 길찾기용)
  1. lab.odsay.com에 가입하고 애플리케이션을 등록합니다.
  2. 애플리케이션의 플랫폼 설정에서 URI를 고르고, 이 파일을 올린 주소(예: https://내아이디.github.io)를 등록합니다.
  3. 발급된 키를 위에 붙여넣습니다. 키는 이 브라우저에만 저장됩니다.

파일을 더블클릭해 바로 열면(file://) 주소가 없어서 ODsay가 거절할 수 있어요. 이 경우 GitHub Pages 같은 곳에 올려서 쓰거나, 키 없이 직접 입력 탭을 쓰면 됩니다.

계산 옵션

길찾기 결과의 갈아타기마다 도보시간에 이 대기시간을 더해 환승 인정 시간(보통 30분)을 넘는지 판단합니다.
